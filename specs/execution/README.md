# Execution plans

Execution plans define how one roadmap phase or vertical slice will be delivered
and verified. The detailed specifications remain authoritative for behavior.

## Phase 0

- [Phase 0A — frontend foundation](./phase-0a-frontend-foundation.md)
- [Phase 0B — backend foundation](./phase-0b-backend-foundation.md)
- [Phase 0 integration checkpoint](./phase-0-integration-checkpoint.md)

Phase 0A and Phase 0B are designed to run concurrently in separate repositories
and Git worktrees. The integration checkpoint begins only after both goals have
met their independent completion criteria.
